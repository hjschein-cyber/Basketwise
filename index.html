Back up or move your data

Manual prices, dates, store names and your basket are stored only in this browser's local storage. They do not sync automatically between phones/computers.

How weekly automatic updates work

When this project is published on GitHub Pages and its scheduled action is enabled, The Farmer is checked every Monday. The latest catalog is downloaded when you open or refresh this app. The timestamp tells you if the feed is current. Failed scrapes never silently replace the previous good snapshot.

The first included reference list covers publicly visible products; it may not be complete. Automatic site extraction depends on The Farmer's page structure and can require maintenance if the website changes.
